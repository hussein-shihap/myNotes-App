# 📱 Notes App (Flutter)

A simple and clean **Notes Application** built with Flutter.  
The app allows users to create, view, edit, and delete personal notes with a modern and easy-to-use interface.

This project focuses on Flutter UI development, navigation, and CRUD operations (frontend level), with future integration of Firebase.

---

## ✨ Features

- 🔐 Login & Register UI screens  
- 📝 Add new notes  
- 📋 Display notes in a list view  
- ✏️ Edit existing notes  
- 🗑️ Delete notes  
- 🎨 Clean and consistent UI design using Theme  
- 📱 Simple and responsive layout  

---

## 🛠️ Tech Stack

- Flutter  
- Dart  
- Material Design
